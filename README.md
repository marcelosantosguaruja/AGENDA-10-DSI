## Lançamento de Notas no Sistema
Para realizar o programa, o usuário precisará informar o Nome completo do aluno, seguido por seu ID e a Disciplina.
Em seguida informar a quantidade de notas para lançamento:
1º Bimestre = 2 notas
2º Bimestre = 4 notas
3º Bimestre = 6 notas
4º Bimestre = 8 notas
Após lançamento o próprio sistema fará o cálculo das médias e se for o caso, trará a nformação se o aluno foi aprovado ou não.
